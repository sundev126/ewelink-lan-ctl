# 网页控制面板设计

## 目标

为服务提供一个浏览器图形界面，用户无需 curl 或快捷指令即可查看插座状态、手动开关插座、完成账号绑定，并获取配置快捷指令所需的设备地址。

## 形态选择

控制面板是由服务本身托管的网页，而不是桌面程序：

- 服务部署在 Debian 服务器或 distroless 容器中，没有桌面环境；网页可在 iPhone、电脑等任意可访问服务的设备上使用。
- 二进制使用 `CGO_ENABLED=0` 交叉编译 Linux 与 Windows 版本，桌面 GUI 工具包通常依赖 CGO 和系统图形库，会破坏现有构建与发布流程。
- 页面文件通过 `go:embed` 编译进二进制，不新增外部依赖、构建步骤或运行时文件。

## 路由

| 方法与路径 | 内容 |
| --- | --- |
| `GET /` | 控制面板页面 |
| `GET /assets/app.css` | 页面样式 |
| `GET /assets/app.js` | 页面脚本 |

与其他路由一致，这些路径只接受 `GET`，其他方法返回 `405` JSON 错误。页面只调用现有的 `/api/v1` 接口，不新增后端接口，也不改变已有接口行为。OAuth 回调成功页改为中文，并提供返回控制面板的链接。

## 功能

- 打开页面时实时读取设备列表；提供手动刷新，页面从后台切回且距上次读取超过 60 秒时自动刷新。不做定时轮询，避免增加云端请求。
- 每个插座显示名称、在线状态和开关状态，并用“开”“关”两个显式按钮控制，请求始终携带明确的 `on` 或 `off`，保持接口幂等，不引入 `toggle`。
- 离线插座禁用开关按钮。控制失败时在对应插座下显示中文错误说明，并保留原状态。
- 未绑定账号（`oauth_required`）时显示绑定提示和指向 `/oauth/start` 的入口，并说明回调地址需能从当前浏览器访问。
- 每个插座提供“快捷指令设置”，展示设备 ID、型号以及可复制的开关地址。
- 顶部汇总插座数量、正在供电与离线数量及最近更新时间。
- 适配手机宽度，跟随系统浅色/深色模式，支持键盘焦点和减少动态效果偏好。

## 安全

- 控制面板与 API 一样不做身份认证，部署要求不变：只允许在可信 LAN、VPN 或带认证的反向代理后访问。
- 页面响应带有严格的 `Content-Security-Policy`（只允许同源脚本、样式和请求，禁止被嵌入框架）、`X-Content-Type-Options: nosniff` 和 `Referrer-Policy: no-referrer`。
- 页面不使用内联脚本和第三方资源，不依赖外部字体或 CDN，在无公网访问的局域网中也可正常使用。
- 开关请求使用 `PUT` 和 JSON 请求体，跨站页面无法在不经过 CORS 预检的情况下发起，服务也不返回 CORS 许可头。
