# README 简体中文翻译设计

## 目标

将项目根目录的 `README.md` 转换为简体中文，方便中文使用者完成配置、部署、OAuth 授权、REST API 调用和 iPhone 快捷指令设置。

## 翻译范围

- 翻译标题、正文、提示信息、表格说明、操作步骤和代码示例中的自然语言注释。
- 保持项目名、技术产品名和通用技术术语不变，例如 OAuth、REST、JSON、Docker Compose、systemd、HTTP、API、LAN、VPN、App Secret 和 device ID。
- 所有命令、文件名、环境变量、URL、API 路径、HTTP 方法、JSON 字段、错误码及示例数据结构保持原样。
- Markdown 结构、章节顺序、警告级别和链接目标保持不变。

## 准确性要求

- 不改变安全边界：整个服务无认证，能访问端口的调用者可以控制设备并重新绑定账号。
- 不改变部署行为、默认值、OAuth 流程、错误状态码或快捷指令阈值。
- 中文表达以准确、直接、易操作为主，避免增加原文没有承诺的功能。

## 验收

- README 中不再保留需要翻译的英文说明段落。
- Markdown 代码块、表格和列表可正常渲染。
- 使用全文对比确认命令、变量名、路径、JSON 字段和关键数值未被误改。
- 运行 `git diff --check`，确保没有格式错误。
